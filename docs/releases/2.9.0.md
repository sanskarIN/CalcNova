## Scope

CalcNova 2.9.0 is the first 2.9-series maintenance baseline after the completed 2.8.03 release. It preserves the existing calculator feature set and cross-platform architecture while strengthening release-version consistency and validation.

Prepared source changes include:

- centralized SDK-independent release identity parsing in `tools/release_identity.py`;
- deterministic display-version to SemVer normalization checks;
- deterministic mobile build-code calculation;
- packaging validation derived from central release identity rather than hardcoded 2.8.03 constants;
- completion-status validation derived from central release identity;
- integrated preflight regression protection for release identity;
- Android and iOS build code `20900`;
- in-app About identity and compiled/headless release-label regressions updated to 2.9.0;
- Linux AppStream 2.9.0 stable release metadata while preserving the 2.8.03 release entry;
- the existing maintained Windows, Linux, macOS, Browser/WebAssembly/PWA, Android, and iOS cross-platform source matrix.
