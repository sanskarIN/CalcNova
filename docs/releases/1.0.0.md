## Why 1.0.0 follows 2.9.7

CalcNova carried 2.x version numbers throughout development. None of them were ever released: the repository has no release tag and no published artifact for any 2.x version, so nobody has ever installed CalcNova 2.9.7 or any of its predecessors.

Continuing from 2.9.7 would have claimed a release history the project does not have. 1.0.0 states the actual situation — this is CalcNova's first release — and the version comparators that package managers, app stores and software centres rely on now agree with it.

The development record is preserved rather than discarded:

- [`CHANGELOG.md`](../../CHANGELOG.md) keeps every earlier entry under a pre-release heading;
- [`releases/2.9.0.md`](2.9.0.md), [`releases/2.9.5.md`](2.9.5.md), [`releases/2.9.6.md`](2.9.6.md) and [`releases/2.9.7.md`](2.9.7.md) remain as the development checkpoints they always were;
- [`docs/history/`](../history/) keeps the longer-form audit records.

Linux AppStream metadata lists only 1.0.0, because a software centre reading the earlier entries would have offered users a "newer" 2.9.7 that does not exist.

## Release scope

CalcNova 1.0.0 is a complete local-first calculator. Included:

- standard, scientific and exact-rational arithmetic, engineering notation, and a programmer mode with bases 2–36 and fixed-width bitwise operations;
- Unicode code-point inspection, unit conversion, statistics including bivariate regression, equation solving, matrices and graphing;
- currency conversion with an offline-capable cache, calculation history with search, favourites and export, and persisted settings with schema migration;
- English and Hindi localization, keyboard-first operation, adaptive layout, high contrast and reduced motion;
- Desktop, Browser/WebAssembly, Android and iOS application heads sharing one view-model layer.
