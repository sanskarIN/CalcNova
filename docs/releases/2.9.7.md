## Evidence policy

Source presence and source-level validators are not substitutes for external execution evidence. Use only observed results:

```text
PASS / FAIL / BLOCKED / NOT RUN
```

In particular, compiled .NET build/test, downloaded desktop artifact execution, Browser runtime checks, Android/iOS device execution, accessibility-tool runs, signing, notarization, store processing, SBOM/checksum publication, and GitHub provenance execution are marked PASS only after those operations actually run and are observed.
