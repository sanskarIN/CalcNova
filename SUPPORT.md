# CalcNova Support

**Current supported product baseline: CalcNova 2.9.6.**

CalcNova is an open-source project. Choose the support channel that matches the issue so requests can be handled efficiently.

## Bugs

Use the GitHub bug-report form for reproducible software defects:

https://github.com/sanskarIN/CalcNova/issues/new/choose

Include:

- CalcNova version or commit;
- platform and OS version;
- reproduction steps;
- expected behavior;
- actual behavior;
- safe screenshots/logs where useful.

Do not include passwords, tokens, signing keys, private documents, or unrelated personal information.

## Feature requests

Use the GitHub feature-request form:

https://github.com/sanskarIN/CalcNova/issues/new/choose

Explain the user problem first, then the proposed solution and platform/accessibility implications.

Feature requests are optional post-2.9.6 enhancements unless they address a confirmed correctness, security, or compatibility defect.
